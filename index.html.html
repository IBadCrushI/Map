Excel → карта рельефа с диаграммами

Загрузите ваш Excel-файл. Приложение распознает столбцы: Координаты, U вкл., В, U отк., В, Градиент (левый) G вкл./откл, Градиент (правый) G вкл./откл, Км по трассе МГ, Техническое состояние КИП.
Подсказка: линия газопровода строится по возрастанию поля «Км по трассе МГ». Если значения отсутствуют — по порядку строк.
