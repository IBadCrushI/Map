Excel → карта рельефа с диаграммами

Загрузите ваш Excel-файл. Приложение распознает столбцы: Координаты, U вкл., В, U отк., В, Градиент (левый), Градиент (правый), Км по трассе МГ, Техническое состояние КИП.
Подсказка: линия газопровода строится по возрастанию поля «Км по трассе МГ». Если значения отсутствуют — по порядку строк.
